PART 1

Spaceship에서 도메인 사기

Spaceship은 도메인 가격이 저렴하고 인터페이스가 깔끔한 등록 서비스입니다. .com 기준 연 $10 내외입니다.

1

Spaceship 접속 & 회원가입

spaceship.com에 접속한 뒤 Sign Up으로 계정을 만듭니다. 이메일 인증까지 완료하세요.

2

원하는 도메인 이름 검색

홈 화면 검색창에 원하는 이름을 입력합니다. (예: myportfolio)
검색 결과에서 사용 가능한 도메인 목록이 나타납니다.

도메인 고르는 팁: .com이 가장 신뢰도가 높습니다. 이미 사용 중이면 .io나 .co도 좋은 대안입니다. 너무 길거나 특수문자가 들어간 이름은 피하세요.
3

장바구니 담기 & 결제

원하는 도메인 옆 Add to Cart → Checkout을 클릭합니다.
결제 시 1년 구독으로 선택하면 됩니다.

주의: 결제 전 "Domain Privacy Protection" 항목을 확인하세요. 개인정보 보호를 위해 켜두는 것을 권장합니다.
4

DNS 설정 화면으로 이동

결제 완료 후 My Account → Domains에서 구매한 도메인을 클릭합니다.
DNS / Nameservers 탭을 선택하면 DNS 레코드 편집 화면이 나타납니다.

DNS란? "이 도메인에 접속하면 어떤 서버로 연결해줘"라는 주소록입니다. 여기서 GitHub 서버를 가리키도록 설정합니다.
PART 2

GitHub Pages에 도메인 연결하기

Spaceship DNS 설정과 GitHub Pages 설정, 두 곳을 모두 바꿔야 연결이 완료됩니다.

5

Spaceship DNS에 A 레코드 4개 추가

Spaceship DNS 편집 화면에서 아래 레코드를 하나씩 추가합니다. Type: A / Host: @ / TTL: 3600

TypeHostValue (IP 주소)TTL
A@185.199.108.1533600
A@185.199.109.1533600
A@185.199.110.1533600
A@185.199.111.1533600
@ 는 도메인 자체(myblog.com)를 의미합니다. 4개 모두 추가해야 합니다.
6

www 서브도메인용 CNAME 레코드 추가

www.myblog.com 으로도 접속되도록 CNAME 레코드를 추가합니다.

TypeHostValueTTL
CNAMEwwwjch2100.github.io3600
Value 부분은 본인 GitHub 아이디로 바꾸세요. 아이디.github.io 형태입니다.
7

GitHub 저장소 → Custom domain 입력

GitHub 저장소 → Settings → Pages → Custom domain 입력란에 구입한 도메인을 입력합니다.

# 예시 Custom domain: myblog.com

Save를 누르면 GitHub가 DNS 확인을 시작합니다. 수 분~최대 24시간이 걸릴 수 있습니다.

8

HTTPS 강제 적용

DNS 확인이 완료되면 Enforce HTTPS 체크박스가 활성화됩니다. 반드시 체크하세요.

HTTPS가 중요한 이유: 브라우저 "안전하지 않음" 경고 없이, 검색엔진 신뢰도도 높아집니다. GitHub Pages는 HTTPS를 무료로 제공합니다.
9

접속 확인

브라우저에서 구입한 도메인을 직접 입력해 페이지가 열리는지 확인합니다.
주소창 왼쪽에 자물쇠 아이콘(🔒)이 보이면 완료입니다.

바로 안 열린다면? DNS 전파에 시간이 걸립니다. 최대 24시간 기다려 보세요. dnschecker.org에서 전파 상태를 확인할 수 있습니다.

전체 흐름 한눈에 보기

헷갈릴 때 이 표만 보세요.
