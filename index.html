한눈에 보는 3단계

결론부터 — 이 세 가지가 전부입니다.

1

HTML 파일 만들기

내 내용을 담은 .html 파일 하나를 준비합니다. AI가 대신 만들어 줍니다.

2

GitHub에 올리기

GitHub 계정을 만들고, 파일을 저장소(repository)에 업로드합니다.

3

GitHub Pages 켜기

설정 한 번으로 아이디.github.io/이름 주소가 자동 생성됩니다.

알고 시작하면 쉬운 개념 둘

이것만 이해하면 전체 흐름이 보입니다.

A

HTML — 웹페이지의 실체

웹페이지는 사실 텍스트 파일입니다. 확장자가 .html인 이 파일에 제목·본문·이미지 위치 등을 적어두면, 브라우저(크롬·엣지)가 읽어서 우리 눈에 예쁘게 보여 줍니다.

<!-- index.html 의 기본 구조 --> <!DOCTYPE html> <html lang="ko"> <head><title>내 페이지</title></head> <body> <h1>안녕하세요!</h1> <p>여기에 내용을 씁니다.</p> </body> </html>
B

GitHub Pages — 무료 서버

내 파일을 GitHub에 올려두면, GitHub가 그 파일을 전 세계 누구나 볼 수 있는 서버에 올려 줍니다. 이 서비스가 GitHub Pages입니다. 별도 서버 구입이나 월정액 없이 무료로 사용할 수 있습니다.

내 주소 형태: https://아이디.github.io/저장소이름
예시: GitHub 아이디가 kim, 저장소 이름이 mysite라면
→ https://kim.github.io/mysite

단계별 따라하기

순서대로 하면 처음이어도 배포까지 완료됩니다.

1

목표와 내용 초안 정하기

"어떤 페이지를 만들 건가요?" — 딱 한 줄로 목적을 씁니다. 참고하고 싶은 웹사이트 하나와, 올리고 싶은 내용 초안(제목·소개 문구 등)을 메모장에 적어 두세요.

2

AI로 HTML 만들기

ChatGPT, Claude, Gemini 중 편한 AI를 열고 이렇게 요청합니다:

# AI에게 보내는 프롬프트 예시 "[참고 사이트 주소]와 비슷한 레이아웃으로, 아래 내용을 담은 index.html 파일을 만들어 줘. [내 내용 초안]"

코드를 받으면 복사 → 메모장에 붙여넣기 → index.html로 저장 → 브라우저로 열어 확인합니다.

더 편한 방법: Claude Code 같은 코딩 에이전트를 사용하면 파일 생성부터 GitHub 업로드까지 자동으로 처리해 줍니다.
3

GitHub 계정 만들기

github.com → Sign up → 이메일·비밀번호·사용자 이름 입력 후 이메일 인증까지 완료합니다. 사용자 이름이 주소의 일부가 되므로 신중히 정하세요.

4

저장소(Repository) 만들기

GitHub 로그인 → 오른쪽 위 ＋ → New repository → 이름 입력 → Public 선택 → Create repository.

꼭 Public으로 설정하세요. Private이면 GitHub Pages를 무료로 사용할 수 없습니다.
5

파일 올리기

저장소 페이지 → Add file → Upload files → index.html 드래그 → Commit changes 클릭.

6

GitHub Pages 켜기

저장소 → Settings → Pages → Source: Deploy from a branch → Branch: main, 폴더: / (root) → Save. 1~3분 후 주소가 나타납니다.
