STEP 1

한눈에 보는 3단계

결론부터 먼저 봅니다. 세 문장으로 전부입니다.

1

콘텐츠를 HTML 파일로 만든다

내가 올리고 싶은 글·이미지·레이아웃을 담은 파일 하나를 준비합니다.

2

GitHub에 파일을 올린다 (push)

GitHub 계정을 만들고, 내 파일을 저장소(repository)에 업로드합니다.

3

GitHub Pages를 켜면 주소가 생긴다

설정 한 번이면 아이디.github.io/저장소이름 주소로 전 세계에서 접속 가능합니다.

💡

GitHub Pages란? GitHub가 무료로 제공하는 정적 웹 호스팅 서비스입니다. 내 저장소의 HTML 파일을 전용 서버에 올려 두고, 전 세계 누구나 그 주소로 접속해 볼 수 있게 해 줍니다. 별도의 서버 구입이나 월정액 비용이 없습니다.

STEP 2

조금 더 알고 시작하기

각 단계가 왜 필요한지, 무엇을 준비해야 하는지 설명합니다.

STEP 1

HTML이 뭔가요? — 웹페이지의 실체

웹페이지는 결국 텍스트 파일입니다. 확장자가 .html인 이 파일 안에 내용·구조·디자인을 담습니다.

HTML은 마치 "이 부분은 제목이고, 이 부분은 사진이고, 이 부분은 본문이야"라고 표시하는 태그 언어입니다. 브라우저(크롬·엣지)가 그 태그를 읽어 우리 눈에 예쁘게 보여 줍니다.

  • 가장 단순한 형태 : index.html 파일 하나면 웹페이지 완성
  • 디자인을 더하려면 CSS, 동작을 더하려면 JavaScript를 함께 씁니다 (나중에 배워도 됩니다)
  • AI(ChatGPT, Claude, Gemini 등)에게 "이런 내용으로 HTML 만들어줘"라고 하면 바로 코드를 뽑아 줍니다
✅

HTML을 처음 배울 때 가장 쉬운 방법: AI에게 원하는 페이지 레이아웃을 설명하고 코드를 받은 뒤, 브라우저에서 직접 열어 확인하는 것입니다.

STEP 2

GitHub — 코드를 저장하고 버전을 관리하는 곳

GitHub는 전 세계 개발자들이 코드를 저장하고 공유하는 플랫폼입니다. 우리에게 중요한 점은 딱 두 가지입니다.

  • 저장소(Repository) : 내 프로젝트 파일을 담는 폴더. 공개(Public)로 만들어야 Pages를 무료로 쓸 수 있습니다.
  • Push : 내 컴퓨터의 파일을 GitHub 서버로 올리는 행위. "저장 후 업로드"라고 생각하면 됩니다.
⚠️

자주 하는 오해: GitHub에 파일을 올리는 것 자체가 웹페이지를 만드는 게 아닙니다. 파일을 올린 뒤 GitHub Pages 기능을 따로 켜야 비로소 인터넷 주소가 생깁니다.

STEP 3

GitHub Pages — 무료 서버, 내 주소 생성

GitHub Pages를 켜면 아래 형태의 주소가 자동으로 발급됩니다.

# 기본 Pages 주소 형태
https://아이디.github.io/저장소이름

# 예시: GitHub 아이디가 kim이고, 저장소 이름이 mysite라면
https://kim.github.io/mysite

이 주소에 접속하면 GitHub 서버가 저장소 안의 index.html을 자동으로 불러와 보여 줍니다. 파일을 수정하고 다시 push하면 주소도 자동으로 업데이트됩니다.

🌐

나중에 내 도메인(예: myblog.com)을 연결하고 싶다면? 도메인을 구매한 뒤 GitHub Pages Custom Domain 설정에서 연결하면 됩니다. 지금은 몰라도 됩니다.

목표 정하기 — "어떤 페이지를 만들 건가요?"

무작정 시작하면 방향을 잃습니다. 먼저 딱 하나만 결정하세요.

  1. 내 페이지의 목적을 한 줄로 씁니다. (예: "내 자기소개 페이지", "카페 메뉴 페이지")
  2. 참고할 웹페이지를 하나 고릅니다. 마음에 드는 디자인이 있는 사이트면 됩니다.
  3. 올릴 내용 초안을 메모장에 적습니다. (제목, 소개 문구, 섹션 구성 등)
💬

AI에게 이렇게 말하세요: "[참고 사이트 주소]처럼 생긴 레이아웃으로, [내 내용 초안]을 담은 HTML 파일을 만들어 줘."

HTML 파일 만들기 — AI에게 부탁하는 법

아래 순서로 진행하면 HTML을 직접 배우지 않아도 파일을 얻을 수 있습니다.

  1. ChatGPT, Claude, Gemini 중 편한 AI를 엽니다.
  2. "다음 조건으로 index.html 파일을 만들어 줘" 라고 요청합니다.
  3. AI가 코드를 출력하면 전체를 복사합니다.
  4. 메모장(또는 VS Code)을 열고 붙여 넣은 뒤 index.html 이름으로 저장합니다.
  5. 파일을 더블클릭해 크롬으로 열어 봅니다 — 이것이 최종 결과물입니다.
<!-- index.html 의 최소 구조 -->
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8">
    <title>내 페이지 제목</title>
  </head>
  <body>
    <h1>안녕하세요!</h1>
    <p>여기에 내용을 씁니다.</p>
  </body>
</html>
⚠️

AI가 만든 코드에 오류가 있으면 브라우저에서 이상하게 보입니다. 그냥 AI에게 "이 부분이 깨져 보여, 고쳐 줘"라고 다시 말하면 됩니다.

GitHub 계정 만들기

  1. github.com에 접속합니다.
  2. Sign up 버튼을 클릭합니다.
  3. 이메일·비밀번호·사용자 이름(username)을 입력합니다.
    ⚠️ username이 곧 웹 주소의 일부가 됩니다. 신중하게 정하세요.
  4. 이메일 인증을 완료하면 계정 생성 완료.

저장소(Repository) 만들기

  1. GitHub 로그인 후 오른쪽 위 ＋ → New repository를 클릭합니다.
  2. 저장소 이름을 입력합니다. (예: mysite)
  3. Public으로 설정합니다. (Private이면 Pages를 무료로 못 씁니다)
  4. Add a README file에 체크합니다.
  5. Create repository를 클릭합니다.
📌

저장소 이름은 나중에 주소의 일부가 됩니다: 아이디.github.io/mysite

파일을 GitHub에 올리기 (Upload)

터미널·Git 명령어를 몰라도 됩니다. 브라우저에서 바로 올릴 수 있습니다.

  1. 만든 저장소 페이지로 이동합니다.
  2. Add file → Upload files를 클릭합니다.
  3. 만들어 둔 index.html을 드래그하거나 선택합니다.
  4. 아래 Commit changes를 클릭합니다. ("저장" 개념)
🚀

더 편하게 하려면: Claude Code 같은 코딩 에이전트를 연결하면 "이 내용으로 페이지 업데이트해 줘"라고 말하는 것만으로 파일 수정과 GitHub push까지 자동으로 처리해 줍니다.

GitHub Pages 켜기

  1. 저장소 상단 탭에서 Settings를 클릭합니다.
  2. 왼쪽 사이드바에서 Pages를 클릭합니다.
  3. Source 항목에서 Deploy from a branch를 선택합니다.
  4. Branch를 main, 폴더를 / (root)로 설정 후 Save를 클릭합니다.
  5. 1~3분 기다리면 페이지 상단에 주소가 나타납니다.

완성! 주소 확인 및 공유

  1. Settings → Pages 화면 상단에 https://아이디.github.io/저장소이름 주소가 표시됩니다.
  2. 링크를 클릭해 브라우저에서 확인합니다.
  3. 이 주소를 SNS, 명함, 이메일에 넣으면 됩니다.
🎉

앞으로 내용을 바꾸고 싶으면 index.html을 수정하고 다시 GitHub에 올리기만 하면 됩니다. 주소는 그대로 유지됩니다.
